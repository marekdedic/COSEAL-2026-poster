		\begin{block}{HPO formalisation}
			Formally, a HPO method \( \tau \) is a function that proposes a hyperparameter configuration \( \hat{\lambda} \) to try next:
			\[
				\hat{\lambda} = \tau \left( \mathcal{D}, \mathscr{F}, \tilde{\Lambda}, \rho \right)
			\]
			given
			\begin{itemize}
				\item \( \mathcal{D} \): dataset
				\item \( \mathscr{F} \): learning algorithm
				\item \( \tilde{\Lambda} \): search space
				\item \( \rho \): performance metric
			\end{itemize}
			\adjustbox{width=\columnwidth}{%
				\includegraphics{images/HPO-loop.pdf}%
			}
			\begin{center}Hyperparameter optimization visualized -- figure by \cite{bischl_hyperparameter_2023}.\end{center}
		\end{block}

		\begin{block}{Cross-RF Transfer Learning}
			\begin{itemize}
				\item Extract graph properties $\delta(\mathcal{D})$ (structure, homophily, attributes, \ldots)
				\item Train a Random Forest metamodel $\mathcal{M}_\rho$ on past HPO runs across multiple datasets
				\item For a new dataset, predict the best hyperparameter configuration directly:
			\end{itemize}
			\begin{equation*}
				\tau\!\left(\mathcal{D}\right) = \argmax_{\lambda \in \tilde{\Lambda}}\; \mathcal{M}_\rho\!\left(\delta\!\left(\mathcal{D}\right),\, \lambda\right)
			\end{equation*}

		\end{block}

		\begin{alertblock}{Key Takeaways}
			\begin{itemize}
				\item \textbf{SMBO is the go-to for GNN HPO}: BO and TPE consistently win; random search is a strong budget option; Sobol QMC disappoints despite theoretical appeal
				\item \textbf{Graph properties predict good hyperparameters}: Cross-RF uses dataset characteristics (homophily, structure, attributes) to warm-start HPO with zero evaluations on the new dataset
				\item \textbf{Transfer learning pays off}: Cross-RF achieves average rank 1.78, outperforming BO (2.00) and TPE (2.22) across 9 diverse graph datasets
			\end{itemize}
		\end{alertblock}
